# Business Performance Dashboard

## Project Overview
This Power BI dashboard provides a deep dive into the operational and financial performance of **Bella Belleza**. The project transforms raw business data into actionable insights, focusing on profitability, marketing efficiency, and staff productivity.

## Key Performance Areas
- **Financial KPIs:** Comprehensive analysis of Total Revenue, Net Profit, and overall margins.
- **Marketing Insights:** Evaluation of ad channels and **ROAS** (Return on Ad Spend) to optimize budget allocation.
- **Stylist Productivity:** Performance tracking for individual stylists to improve service quality.
- **Customer Behavior:** Insights into customer retention rates and purchasing patterns.

## Tools & Technologies
- **Power BI:** Data modeling, DAX queries, and interactive visualization.
- **Microsoft Excel:** Source data management and initial cleaning.

## Repository Structure
The project is organized as follows:
- **`powerbi/`**: Contains the `.pbix` dashboard file.
- **`data/`**: Includes the `business_data.xlsx` file.
- **`analysis/`**: Contains the full PDF analysis report.
- **`dashboard/`**: High-quality screenshots for quick preview.
